# Shailja Lavania | Public Policy & Political Researcher

Public portfolio: https://shailja-lavania.github.io/

Built with HTML, CSS and JavaScript. GitHub Pages publishes the root of `main`; no package installation or build step is required. `.nojekyll` enables direct static serving.

## Editing

- `index.html`: text, project links, contacts, photographs and research journey.
- `styles.css`: colours, layout and responsive styles.
- `script.js`: independent accessible photo sliders and mobile navigation.
- `assets/images/`: optimized photographs and article chart.
- `assets/documents/`: supplied CV and optimized community report.
- `writing/`: browser-readable draft article.

Sections: Home, Story, Research, Projects, Publications, Impact, CV and Contact. The homepage has three slides; the Kiul gallery has ten distinct photos. Update each slider's count, accessible labels and captions when changing photographs.

The CV preserves the supplied PDF exactly. The community report is a smaller web copy retaining all 66 pages. The writing sample is labelled as a draft.

The separate local `dev` checkout and restricted Sites deployment remain available for reviewing future changes. Changes become public here when pushed to `main`.
